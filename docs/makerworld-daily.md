# מודלים חדשים מהאוספים, כל יום, לבד

המטרה: מודל שאתה שומר לאוסף בבמבו בערב מחכה לך לאישור ב-`/admin` בבוקר, בלי
שתעשה שום דבר.

## למה זה לא רץ על GitHub

הכל כבר בנוי שם: `.github/workflows/sync-collections.yml` רץ פעמיים ביום,
והעוגייה שלך כבר שמורה ב-Secrets. ההרצה של היום דיווחה `signedIn: true` ואז
`Cloudflare` על **כל שמונת האוספים**.

זאת לא בעיית הרשאה, זאת בעיית כתובת. Cloudflare מגיש אתגר אבטחה לעמודי
האוספים לכל כתובת של מרכז נתונים — גם ל-runners של GitHub, גם לשירות דפדפן
מארח (נבדקו שניהם, שניהם קיבלו "Just a moment…"). ה-API של המודלים דווקא עונה
להם יפה, וזה מה שמאפשר ייבוא לפי קישור. העמודים לא.

מה שלא נחסם: **חיבור ביתי**. כלומר המחשב שלך.

## ההתקנה — פעם אחת

### 1. פרופיל דפדפן מחובר

```bash
cd "D:\...\unit3d"
set MAKERWORLD_PROFILE_DIR=%CD%\data\mw-profile
npm run sync:collections -- --login
```

נפתח דפדפן רגיל. תתחבר למייקרוורלד כרגיל, תחזור לטרמינל ותלחץ Enter.

הפרופיל נשמר ב-`data/mw-profile/` — **הוא ב-gitignore ולא עולה לשום מקום**.
מכאן כל הרצה כבר מחוברת, והאתר מרענן את העוגיות של הפרופיל הזה כמו של כל
משתמש אחר. אין מה להדביק מחדש כשמשהו פג.

### 2. משימה יומית

Task Scheduler → Create Task:

| שדה | ערך |
|---|---|
| Name | `Unit3D MakerWorld Sync` |
| Trigger | Daily, 07:45 |
| Action | `scripts\sync-daily.bat` |
| Start in | תיקיית הריפו |
| Run whether user is logged on or not | ✓ |

זה בדיוק אותו דפוס של המשימות שכבר רצות אצלך.

### 3. זהו

`scripts/sync-daily.bat` מושך, קורא את האוספים ואת הלייקים, מוסיף מה שחדש
לתור האישור, מוריד תמונות, **בודק טיפוסים** ורק אז דוחף. אם הבדיקה נופלת הוא
לא דוחף כלום ורושם את זה ביומן. יומן ריצה: `scripts/sync-daily.log`.

## מה זה עושה ומה זה לא

| כן | לא |
|---|---|
| קורא את כל האוספים והלייקים | לא מאשר מודלים |
| מוסיף מה שעוד לא בחנות לתור האישור | לא מחליט מדף סופי |
| מוריד תמונות ומחשב משקל וזמן | לא מעלה מודל לחנות בלי לחיצה שלך |
| זורק רישיון לא-מסחרי ונשק | |

**אישור נשאר שלך.** זה לא מגבלה טכנית, זו הנקודה: אתה מחליט אם מוכרים ובאיזה
מדף, וזו לחיצה אחת. סקריפט שמאשר בשמך מנחש בשתי השאלות.

## אם זה מפסיק לעבוד

1. `scripts/sync-daily.log` — מה הריצה האחרונה אמרה.
2. `data/collections-status.json` — מה היא ראתה: `signedIn`, אילו אוספים נקראו,
   ואילו נחסמו.
3. אם `signedIn: false` — הפרופיל התנתק. להריץ שוב את שלב 1.

## ה-workflow ב-GitHub

הוא נשאר מופעל. הוא לא מזיק, הוא רושם מה קרה, ואם Cloudflare יפסיק לחסום
כתובות שרתים הוא יעבוד שוב לבדו. המשימה במחשב היא מה שעובד היום.
