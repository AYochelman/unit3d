# מודלים חדשים מהאוספים — כל יום, לבד

**המדריך המלא הוא [`makerworld-daily.html`](./makerworld-daily.html)** — לפתוח
אותו בדפדפן (הקלקה כפולה על הקובץ).

הוא בפורמט HTML ולא Markdown בכוונה: הוא מדריך הפעלה למסך, לא לקריאה
בטרמינל. כל שלב שם אומר במפורש באיזו תוכנה פותחים, איך פותחים אותה, לאיזו
תיקייה הולכים, ומה אמור להופיע על המסך — וזה לא נקרא טוב כטקסט רגיל.
