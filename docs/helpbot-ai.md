# העוזר באתר — AI אמיתי

העוזר (הכדור החושב) עונה עכשיו דרך Claude, מתוך המידע של האתר בלבד.
עד שהשלבים כאן נעשים, הוא ממשיך לענות מהתשובות המוכנות כמו קודם — שום דבר לא נשבר.

## איך זה בנוי

- `/helpbot-knowledge.txt` — נבנה עם האתר בכל דחיפה: כל המוצרים עם המחיר שהאתר גובה,
  המדפים, התשובות המוכנות, השאלות הנפוצות ופרטי הקשר. זה כל מה שה-AI יודע.
- `supabase/functions/helpbot/index.ts` — פונקציה ב-Supabase שמחזיקה את מפתח ה-API
  (לא באתר, שם כל אחד היה רואה אותו), שולחת את השאלה ל-Claude ומחזירה תשובה וקישורים.
- `lib/helpbot-ai.ts` + `components/HelpBot.tsx` — האתר מנסה קודם את הפונקציה,
  ואם היא לא עונה תוך 25 שניות או לא קיימת — חוזר לתשובות המוכנות.

כללים שה-AI מקבל: עברית קצרה בגוף ראשון, רק עובדות מהמידע, לא ממציא מחירים או מועדים,
לא מבטיח הנחות, ומה שלא יודע — מפנה לוואטסאפ. קישורים רק לעמודי האתר או לוואטסאפ.
אין לו גישה להזמנות, ללקוחות או לשום מידע פרטי, והוא לא כותב לשום מקום.

## מה צריך לעשות (פעם אחת)

### 1. מפתח API של Anthropic
1. https://console.anthropic.com ← **API Keys** ← **Create Key**. שם: `unit3d-helpbot`.
2. מומלץ: **Billing → Limits** — להגדיר תקרת הוצאה חודשית (למשל 20$), כדי שאף פעם לא תהיה הפתעה.
3. להעתיק את המפתח (`sk-ant-...`). לא לשלוח אותו לאף אחד ולא להדביק אותו בקוד.

### 2. הפונקציה ב-Supabase (מהדפדפן, בלי להתקין כלום)
1. Supabase ← הפרויקט של החנות ← **Edge Functions** ← **Deploy a new function** ← **Via Editor**.
2. שם הפונקציה: `helpbot` (בדיוק ככה).
3. למחוק את הקוד לדוגמה ולהדביק את כל התוכן של `supabase/functions/helpbot/index.ts` ← **Deploy**.
4. בפונקציה ← **Details / Settings** ← לכבות את **Verify JWT** (המפתח הציבורי של האתר הוא
   מהסוג החדש, והבדיקה הזו חוסמת אותו. הפונקציה פתוחה לאתר ממילא, ומוגבלת בקצב ובאורך).
5. **Edge Functions → Secrets** (או Project Settings → Edge Functions) ← **Add secret**:
   שם `ANTHROPIC_API_KEY`, ערך — המפתח מסעיף 1.

זהו. מהשאלה הבאה בעוזר — התשובה מגיעה מה-AI.

### עם ה-CLI (אם מעדיפים)
```bash
supabase functions deploy helpbot --no-verify-jwt
supabase secrets set ANTHROPIC_API_KEY=sk-ant-...
```

## עלות

המודל: Claude Opus 5.5 ברמת מאמץ נמוכה. ההוראות והמידע של האתר (כ-20 אלף טוקנים) נשמרים
במטמון, כך שמההודעה השנייה הם עולים עשירית. הערכה גסה: בערך 1-3 סנט לשאלה. התקרה בסעיף 1.2
היא מה ששומר על זה.

## עדכון המידע

אין מה לעשות: כל דחיפה לאתר בונה מחדש את `/helpbot-knowledge.txt`, והפונקציה מושכת אותו
מחדש כל 10 דקות. מוצר חדש, מחיר שהשתנה או שאלה נפוצה חדשה — העוזר יודע עליהם אחרי הפרסום.
שינוי בקוד הפונקציה עצמה מחייב להדביק אותה שוב (סעיף 2.3).
