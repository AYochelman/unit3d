# תמונות הקטלוג

כל תמונה שהאתר מציג נשמרת כאן, בתוך הפרויקט, ולא נטענת מהאתר של המעצב.

* להוריד את מה שחסר: `npm run fetch:images`
* שם הקובץ הוא חתימה של הכתובת המקורית, כך שהוא יציב בין הרצות.
* המיפוי מכתובת מקורית לקובץ המקומי נמצא ב-`lib/localImages.generated.ts`.
* תמונה שאין לה עדיין עותק מקומי ממשיכה להיטען מהמקור, כך שכלום לא נשבר בינתיים.

הפעולה רצה גם לבד: `.github/workflows/sync-images.yml` מוריד ומוסיף לגיט כל
תמונה חדשה אחרי שמוסיפים דגם, וגם פעם בשבוע.
