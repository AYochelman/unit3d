איסוף האוספים והלייקים ממייקרוורלד

הדבקה אחת, כל האוספים. בלי להתקין כלום.

שים לב: אל תלחץ פעמיים על קובץ ה-.js. ווינדוס מנסה להריץ אותו כתוכנה ונותן שגיאה. הקוד רץ בתוך הדפדפן בלבד. הדף הזה עושה את זה במקומך.
  1. פתח בלשונית אחרת את מייקרוורלד, מחובר לחשבון שלך. כל עמוד באתר מתאים — לא צריך לפתוח אוסף ולא צריך לגלול.
  2. חזור לכאן ולחץ על הכפתור הירוק — הקוד יועתק.
  3. חזור ללשונית של מייקרוורלד ולחץ F12.
  4. בחר בלשונית Console.
  5. לחץ Ctrl+V ואז Enter.
    אם הדפדפן מבקש לכתוב allow pasting — כתוב את זה, Enter, ואז הדבק שוב.
  6. חכה. הוא עובר אוסף אחרי אוסף ומדפיס התקדמות. בסוף הרשימה מועתקת ללוח.
  7. GitHub ← Actions ← Model candidates ← Run workflow ← להדביק בשדה.
    הכל ייכנס ל"מודלים לאישור" ב-/admin. שום דבר לא עולה לחנות לבד.
להצגת הקוד (לא חובה)

למה בכלל צריך את זה: השרת שלנו לא מצליח לפתוח את דפי האוספים — Cloudflare חוסם אותו. נבדק שוב היום, מחובר עם החשבון שלך, ושמונה מתוך שמונה נחסמו. הדפדפן שלך לא נחסם, כי אתה משתמש אמיתי. (יורד גם makerworld-raw.json, למי שמעדיף את הדרך הישנה עם import-models.bat.)
